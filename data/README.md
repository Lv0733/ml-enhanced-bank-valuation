# Data

The empirical analysis uses quarterly financial and accounting data for
U.S. commercial banks accessed through LSEG Workspace.

The raw LSEG-delivered dataset is not included in this repository because
its distribution is subject to LSEG access and usage terms.

Additional data sources include:

- Federal Reserve Economic Data (FRED)
- Aswath Damodaran's historical implied equity risk premiums

Users attempting to reproduce the analysis should obtain the relevant
data through the appropriate authorized sources.
